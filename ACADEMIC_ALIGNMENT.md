# Academic alignment — added trip-expense journal

The journal is an additive software feature. It does **not** change the source data used to produce past machine-learning, stochastic or operations-research results. Nor does it introduce empirical traveler expenditure data that have not been collected.

- **Data/storage:** structured schema and validation for traveler-supplied observations; link-only publishing for the initial prototype, no central store.
- **Data mining:** future data fields that could be studied include expense category, municipality, travel month and group size; any analysis would require a properly collected sample and provenance checks.
- **ML:** existing reported forecasting comparisons remain unchanged; no new predictive claim is made.
- **Stochastic:** real recorded expenses could eventually motivate cost-range modeling after sufficient data exist; current uncertainty analysis remains unchanged.
- **Operations Research:** a traveler can reuse stops and see recorded per-stop costs as planning context. Those are not yet parameters for the campaign optimization model.
- **Digital Marketing:** shareable firsthand itineraries provide an audience-participation and referral pathway, complementing the source-backed destination campaign and reviewed provider offers.
- **Integration:** the existing plan → route → costs → providers flow gains optional record → share → reuse behavior.

The original rubric additionally addresses problem formulation, interdisciplinary integration, proposal/impact, clear technical communication and colloquium defense. The feature provides an additional demonstrable workflow; it does not replace the analytical materials or require rewriting the rubric.
